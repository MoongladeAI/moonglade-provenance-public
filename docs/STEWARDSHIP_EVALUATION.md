# Evaluating provenance and agent behavior

Provenance can authenticate specified evidence under a trust policy. That does not establish content truth or an improvement in agent behavior.

A useful behavioral study would preregister its tasks, controls, scoring and exclusion rules. Compare runs with and without provenance while keeping standing instructions and operator interaction constant. Publish the runner and any data cleared for disclosure. Report uncertainty and negative results alongside positive ones.

This release does not claim to include such a controlled evaluation.
